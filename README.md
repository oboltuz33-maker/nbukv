# N букв — Telegram Mini App

Один игрок загадывает существительное из N букв (3–10) и отправляет ссылку.
Другой отгадывает его за как можно меньшее число попыток. После каждой попытки:

- серая буква — её нет в слове;
- белая — есть, но на другом месте;
- жёлтая — стоит на своём месте.

Бэкенд не нужен: слово в закодированном виде передаётся в параметре `startapp` ссылки,
прогресс отгадывающего хранится в `localStorage`. В ссылку также записывается имя автора слова,
чтобы отгадавший мог одним нажатием отправить ему результат.

## Файлы

- `index.html` — разметка двух экранов (загадать / отгадать)
- `style.css` — стили, цвета берутся из темы Telegram
- `app.js` — логика игры; настройки в начале файла

## Запуск в Telegram

1. Разместите папку на любом HTTPS-хостинге (GitHub Pages, Netlify, Vercel).
2. В @BotFather: `/newbot` → создайте бота; затем `/newapp` → выберите бота,
   укажите URL хостинга и короткое имя приложения (например `play`).
3. Пропишите в `app.js` значения `BOT_USERNAME` и `APP_SHORT_NAME`.
   Ссылки будут вида `https://t.me/<бот>/<имя>?startapp=<код>`.

## Проверка в браузере

Откройте `index.html` (лучше через локальный сервер, например `npx serve`).
Пока `BOT_USERNAME` не заполнен, ссылки генерируются вида `...index.html?w=<код>`.

## Словарь

Загаданное слово и каждая попытка проверяются по `words.txt` — существительным
в единственном числе из 3–10 букв (ё заменена на е). Список собран из словаря
Harrix Russian-Nouns v2.0, слова «только во множественном числе» (ножницы, сани) убраны.

Пересобрать: распакуйте `russian_nouns_v2.0.7z` и выполните
`node scripts/build-dict.js <папка russian_nouns_v2.0>`.
После изменения `words.txt` поднимите версию в `DICT_URL` в `app.js`.

## Игра с собой

На экране «Загадать» можно выбрать длину (4–8 букв) и получить случайное слово
из `random.txt` — около 2 000 узнаваемых существительных, отобранных тем же скриптом
(без устаревших, местных и разговорных слов, только многозначные). Последние 100
загаданных слов не повторяются; незаконченная игра продолжается после перезапуска.
